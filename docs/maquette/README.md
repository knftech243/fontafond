# Maquette de Fontafond

Référence visuelle validée avant le développement : https://claude.ai/artifact/RPNcqVZZMuZxyPQ4mGqDSV (page privée).

| Fichier | Écran |
|---|---|
| `Projets.dc.html` | Mes polices : créer, modifier une police existante, licence, récents |
| `Main.dc.html` | Éditeur de glyphe : outils, guides, points de Bézier, panneaux |
| `Studio.dc.html` | Studio texte : modes, Caractère, Paragraphe, Style, sélecteur de couleur |
| `canvas.json` | Disposition des écrans sur le canevas |

Ces fichiers sont au format du canevas de design de claude.ai : ils ne s'ouvrent pas seuls dans un navigateur. Ils servent de référence pour les couleurs, la disposition et les textes.
